# Decisions

- Lead kept: no own domain found; mainstreetbarbers.net is a Burlington, VT shop, and hub.biz is a directory page.
- Display name "Main Street Barber Shop" (Google/Fresha/Birdeye); "Main Street Barbers" mentioned only as the Facebook page name.
- Hours: used Tue-Fri 8-5, Sat 8-12 (3 sources agree) over Mon-Sat 8-5 (2 sources); page asks visitors to call to confirm.
- Live open badge kept despite the conflict, because 3 sources agree and the hours line is a single config in app.js.
- Phone: (775) 782-8259 only; ignored the 309-xxxx numbers on Nextdoor/Yahoo as likely tracking numbers.
- No prices anywhere, so every service row is a tap-to-call "Call for price".
- Services limited to those named by Fresha, YellowPages tags, Nextdoor and reviews; hair straightening and women's cuts left off (directory tags only) but no "men only" wording.
- Removed paraphrased praise ("fair prices", "good conversation", "regulars for 10+ years") from the copy per the launch checklist; it lives only in the verbatim quotes.
- Did not call the shop "old-school" in our own copy; that word comes only from the quoted reviews.
- Quotes: used only the 4 that came back identical on two fetches; skipped Fred M. (wording differed between fetches) and Dayna I. (snippet was garbled).
- Nextdoor "Neighborhood Favorite" award not shown: could not confirm it.
- Concept built on "Main Street = US 395": street blade logo, route shield, highway guide-sign price list, mile-marker section numbers. Chosen to look nothing like the pole/brass/card themes of the other barbershop demos.
- Fonts Bricolage Grotesque + Bebas Neue + Work Sans: no sibling demo uses this trio.
- Two-chair illustration with DAN / JEFF plates: illustrates the two named barbers; not presented as a photo of the real interior.
- Book button opens a Call / Text sheet because there is no online booking (Fresha listing is unclaimed).
- Text card says "If it doesn't go through, give them a call" because the number may be a landline.
- Mobile nav shows the MAIN ST blade only (sub-label hidden under 460px) so the open badge and menu fit at 390px and 320px.
- Footer privacy note mentions Google Maps and Facebook links instead of a booking platform, since there is none.
