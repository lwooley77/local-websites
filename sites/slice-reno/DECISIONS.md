# Decisions

- Treated as a lead: slicesalon.com redirects to expireddomains.com and the Vagaro page is 404, so they have no working site.
- Name on the page is "Slice Salon" (Yelp, Birdeye, Nextdoor); Google's short form "Slice" is used for the wordmark.
- No hours shown and no open/closed badge: five sources give five different schedules.
- No staff names: reviews from 2016 to 2023 name ten different stylists and the current team is unknown.
- Book buttons open a call/text sheet because the Vagaro page is dead; BOOKING_URL left empty.
- Quotes taken only from Birdeye's raw HTML (verbatim), credited First name + last initial + Facebook; lowercase start fixed with CSS ::first-letter so the source text stays verbatim.
- Quotes about a single stylist are cut to the sentence about the work, without the stylist's name.
- "Since 2011" used (two sources agree) but listed as Unverified.
- Vivid color listed as a service on the strength of a review describing pink, purple and teal work; flagged Unverified.
- Brows, waxing and eyelash services included from the second Yelp listing and directory categories; eyelash row says to call and check.
- Service descriptions kept to plain definitions so nothing implies prices, timing or policies.
- Palette: warm porcelain, cherry, teal and near-black, to stay far from the red/paper Cutz demo and black/gold Dream demo.
- Fonts: Syne / Space Grotesk / Figtree, none used by the two reference demos.
- Hero art is a hair-color swatch ring, since color is what reviewers praise most.
- The diagonal "slice" cut line is kept in the hero only; in the small nav and footer marks it read as a strikethrough.
- Phone number in the big Call card set in Space Grotesk, not Syne, so it fits 390px without wrapping.
- Quote attributions use <p> instead of <footer> so the page has one real <footer>.
- Text buttons kept even though the number may be a landline; listed under Missing.
